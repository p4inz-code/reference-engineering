# How to Cite Reference Engineering

If you use this framework, methodology, or term in published work — tutorials,
articles, academic papers, talks, courses, or tools — please credit the origin.
Citation is not legally required under MIT, but it is how the discipline grows
with accurate attribution.

## What Counts as Using the Framework

You are using the framework (and citation is encouraged) if you:

- Teach pre-production reference methodology using the terms, principles,
  or structure from this repository
- Build tools, prompts, or AI skills that implement Reference Engineering
  workflows from any discipline in this library
- Publish articles or tutorials that reference the Seven Principles,
  the Reference Pyramid, or the discipline-specific guides from this repo
- Use the term "Reference Engineering" to describe a systematic pre-production
  methodology in published work

You are **not** required to cite if you simply use good reference practices
that happen to align with this framework. The goal is attribution for direct
use, not ownership of the general concept of thinking before you collect.
