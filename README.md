# reference-engineering

> **The only reference engineering library you will ever need — from app dev to VFX.**

<!-- BANNER IMAGE PLACEHOLDER — Session 2 -->
<!-- ![Reference Engineering](./docs/banner.png) -->

**Reference Engineering** is the systematic practice of identifying, gathering,
analyzing, and organizing reference material before and during production —
with the explicit goal of answering specific technical and creative questions,
not merely collecting visual inspiration.

## The Seven Principles

1. Reference answers questions, it does not collect images
2. The gap is more important than the board
3. Different production stages need different reference
4. Reference has a hierarchy
5. Style is a set of extractable rules, not a feeling
6. Reference is never finished, only versioned
7. The discipline transfers across fields

Full principles: [`MANIFESTO.md`](./MANIFESTO.md)
