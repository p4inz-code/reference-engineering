# Example: Post-Apocalyptic Game Environment

**Discipline:** Game Art / 3D Environment
**Asset type:** Modular urban ruins kit for real-time game (UE5, third-person)
**Project prompt:** Build a modular ruins kit for a post-apocalyptic third-person
  action game. Eastern European city block setting. Mid-to-late collapse stage —
  not rubble, not pristine. Structures standing but damaged, reclaimed by nature
  over 15–20 years. Style: grounded realism with slight desaturation, not stylized.
  Target: Fab marketplace + in-house use.

**Framework focus:** Full seven-layer demonstration. This example runs all
Pyramid layers explicitly, including Layer 3 (production stage reference)
across all stages from blockout to hero detail.

**Key skill demonstrated:** Stage-appropriate reference gathering — a separate
reference pass for each production stage rather than one big gather upfront.
