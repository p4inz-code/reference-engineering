# Example: Community Library Renovation

**Discipline:** Architecture
**Project type:** Renovation and addition to a 1960s municipal library
**Project prompt:** Renovate a 1960s brutalist community library in a
  mid-size city. Add a 400sqm extension for a digital media lab and
  flexible community space. Retain and celebrate the original brutalist
  character of the existing building. The extension must be legible as
  new while being respectful of the original.

**Framework focus:** Architecture demonstrates how Reference Engineering
applies to a discipline where the "production" is a building and the
"reference" spans history, physics, climate, regulation, and community
context simultaneously. Layers 1, 5, and 6 are the dominant layers here —
architecture is one of the few disciplines where contextual conditions
(climate, orientation, site) and material behavior (how concrete ages,
how glass performs thermally) are as important as visual style.

**Key skill demonstrated:** Managing reference from multiple simultaneous
domains (historical, technical, regulatory, cultural) without letting
any single domain dominate to the exclusion of others.

## Pyramid Layer Coverage

| Layer | Covered? | Notes |
|---|---|---|
| 1 — Function & Context | ✅ Full | Program, community context, existing building analysis |
| 2 — Scale & Proportion | ✅ Full | Datum, bay module, extension mass |
| 3 — Production Stage | ✅ | Schematic / DD / CD stages mapped |
| 4 — Governing Rules | ✅ Full | Brutalist rules, new/old legibility rules |
| 5 — Contextual Conditions | ✅ Full | Climate, orientation, daylighting |
| 6 — Behavior & Construction | ✅ Full | Concrete behavior, thermal performance |
| 7 — Precision Detail | ~ Partial | Material specification detail |
