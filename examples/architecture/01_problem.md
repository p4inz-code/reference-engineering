# Architecture — Problem & Brief

**Project:** Community Library Renovation + Digital Media Lab Extension
**Stage:** Pre-design / Schematic Design
**Brief version:** 1.0

---

## The Problem Without Reference Engineering

Architecture fails at reference in two specific ways:

**Failure Mode A — Precedent Mimicry:** The designer finds a well-photographed
precedent project (a celebrated brutalist renovation) and uses it as the
primary visual guide. The result references the photograph rather than the
principles that produced the photograph. When the site conditions, climate,
program, and scale are different from the precedent — as they always are —
the mimicry produces work that looks like a copy without the logic that
made the original successful.

**Failure Mode B — Single-Domain Reference:** The designer references
heavily in one domain (visual/aesthetic) and lightly in others (structural
behavior, climate performance, regulatory compliance). The project looks
right and performs wrong. Buildings that look correct but fail at thermal
performance, or that follow aesthetic precedent from a different climate,
are the product of single-domain reference.

Reference Engineering prevents both by requiring explicit reference across
all Pyramid layers — with the discipline that no layer's absence is permitted
to hide behind another layer's abundance.

## Production Questions — Brief v1

### Layer 1 — Function & Context

**Program:**
- [ ] What is the existing library's floor area and current program distribution?
- [ ] What does the digital media lab specifically contain? (servers, maker equipment, AV, recording — each has different spatial and MEP requirements)
- [ ] What is "flexible community space" in the specific context of this community? (town halls? workshops? performances? — each configures differently)
- [ ] What is the existing building's structural system? (brutalist concrete almost always bears loads on expressed concrete walls — the extension must not transfer loads onto a structure not designed for it)

**Community context:**
- [ ] What is the community's relationship to the existing building? (loved, ignored, feared — brutalism divides opinion; the community's view affects the renovation approach)
- [ ] Who are the primary user groups for the extension? (age distribution, digital literacy, accessibility requirements)
- [ ] What is the building's civic significance? (heritage listed? locally significant? anonymous municipal? — this affects the regulatory approach and the conservation obligation)

**Existing building analysis:**
- [ ] What is the existing building's datum? (the primary horizontal line that organizes the facade — all extension decisions reference this)
- [ ] What is the existing structural bay module?
- [ ] What materials is the existing building actually made of? (fair-face concrete? brick aggregate? precast panels? — crucial for material continuity decisions)
- [ ] What is the existing building's worst-performing element? (the thing most in need of remediation that the renovation must address)

### Layer 2 — Scale & Proportion

- [ ] What is the existing building's height and the height of its primary datum line?
- [ ] What is the site area available for the extension?
- [ ] What height limit applies? (planning regulations, not aesthetic preference)
- [ ] What is the extension-to-existing ratio? (400sqm extension against existing floor area — is the extension subordinate, equal, or dominant in mass?)
- [ ] What is the setback requirement from site boundaries?

### Layer 3 — Production Stage (Schematic Design)

*At schematic stage: need mass/volume reference, not detail.*
- [ ] What precedents exist for brutalist building renovation with contemporary additions?
- [ ] What are the three primary approaches to "new legible, old respected"? (contrast, complement, continuation — precedents for each)
- [ ] What has failed in this problem type? (what renovations have been criticized for getting this wrong)

### Layer 4 — Governing Rules

- [ ] What are the specific visual rules of this existing building's brutalism? (expressed structure? board-formed concrete? punched windows? brise-soleil? — not all brutalism uses the same elements)
- [ ] What makes this building "brutalist" specifically vs. generically "1960s institutional"?
- [ ] What must the extension NEVER do? (visually compete with the existing facade? replicate brutalist concrete in new construction? obscure the original building's primary entrance?)
- [ ] What is the minimum intervention that would satisfy the brief? (useful constraint — keeps the extension subordinate to program rather than ego)

### Layer 5 — Contextual Conditions

- [ ] What is the building's orientation? (which facade faces which direction — daylighting strategy depends entirely on this)
- [ ] What is the local climate? (heating-dominated vs cooling-dominated — affects glazing strategy, thermal mass strategy, shading requirements)
- [ ] What is the solar angle at the latitude? (determines shading device depth — a critical design parameter that cannot be guessed)
- [ ] What wind conditions apply to the site? (affects natural ventilation strategy)
- [ ] What is the acoustic environment? (a digital media lab next to a noisy road has different requirements than the same lab in a quiet neighborhood)

### Layer 6 — Behavior & Construction

- [ ] What is the condition of the existing concrete? (carbonation depth, rebar cover, spalling, ASR — the renovation approach depends on this diagnosis)
- [ ] What is the thermal performance of the existing envelope? (almost certainly poor by current standards — what is the target and what interventions are possible?)
- [ ] What new structural system does the extension use? (must not transfer loads onto existing structure unless analysis confirms capacity)
- [ ] How does new concrete (if used) relate to 60-year-old concrete? (color match is almost impossible — this is a design decision, not a specification problem)

### Layer 7 — Precision Detail (Defer to Design Development)

- [ ] Joint details between existing and new construction
- [ ] Concrete specification for exposed new concrete (if used)
- [ ] Entrance canopy detail and connection to existing

## Reference Tier Plan

| Question category | Expected tier | Source plan |
|---|---|---|
| Existing building documentation | Primary | Site survey, as-built drawings, photographic record |
| Precedent renovations | Secondary | Published precedent projects, same building type |
| Brutalist design principles | Primary | Original architects' writings, period documentation |
| Climate/performance data | Primary | Local weather data, BRE/ASHRAE standards |
| Regulatory requirements | Primary | Local planning authority, conservation officer |

## Gap Risk Assessment

| Gap | Risk | Priority |
|---|---|---|
| Existing structural system undocumented | HIGH — extension structure cannot be designed without this | CRITICAL |
| Heritage listing status unknown | HIGH — changes entire regulatory and design approach | CRITICAL |
| Existing concrete condition unassessed | HIGH — renovation scope depends on condition | CRITICAL |
| Solar angles not calculated | MEDIUM — shading strategy will be wrong | HIGH |
| Community relationship to building unknown | MEDIUM — affects political and cultural approach | MEDIUM |
