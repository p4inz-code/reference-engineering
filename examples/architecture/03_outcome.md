## Massing Decisions

**D01 — Extension configuration: 18m × 22m (3 bays × 3.7 bays), single story**
The more compact configuration creates a courtyard between extension and
existing building. The courtyard becomes a covered link space — addressing
the entrance wayfinding problem the community identified without adding
separate floor area.
Reference: Site area analysis (T1), community consultation (T1)
Confidence: CONFIRMED

**D02 — Extension height: 5.0m to parapet**
Subordinate to existing (5.4m to parapet). Height difference is legible
but not dramatic — the extension reads as family member, not servant wing.
Reference: Planning authority height limit 7.5m (T1), subordination principle (T2)
Confidence: CONFIRMED

**D03 — Structural grid: 6.0m × 6.0m — aligns with existing**
Grid alignment makes the family relationship explicit. The extension counts
the same bays as the existing building. Where grids align at junction,
the structural logic is continuous even where materials differ.
Reference: Existing as-built structural drawings (T1), Approach B precedent analysis (T2)
Confidence: CONFIRMED

## Entrance and Wayfinding Decisions

**D04 — New covered courtyard resolves existing wayfinding failure**
The community identified the entrance as hard to find. Root cause: the datum
line (900mm raised floor) visually dominates the entrance. The courtyard
pulls both the existing entrance and the new extension entrance into a shared
arrival space — a new datum element at grade that announces "this is where
you arrive."
Reference: Community consultation (T1), existing building analysis (T1)
Confidence: CONFIRMED

**D05 — Extension entrance: secondary in hierarchy to existing**
The existing entrance remains primary. Extension entrance enters the courtyard,
not the street. Visitors approach the courtyard first and then choose their
destination — library or digital media lab — from within the courtyard.
Reference: Governing rule — extension never competes with existing primary entrance (T1)
Confidence: CONFIRMED

## Material and Expression Decisions

**D06 — Extension columns: smooth-formed new concrete, expressed**
Same structural language as existing (expressed columns). Different surface
(smooth-formed vs board-formed). The difference is legible from 5m.
The same material is used in both periods — the process distinction
acknowledges the generation difference.
Reference: New/old concrete behavior analysis (T1), Approach B precedent (T2)
Confidence: SUPPORTED — one design principle confirmed by one precedent.
Additional precedent desirable before DD locks this decision.

**D07 — Extension infill: contemporary glazing system, not brick**
The existing infill is brick between concrete columns. The extension infill
is a contemporary aluminum-framed glazing system. Clearly contemporary,
clearly infill in the same structural logic. The material change is the
legibility of newness.
Reference: Governing rule — infill is secondary to frame (T1 derived rule)
Confidence: CONFIRMED

**D08 — Board-formed concrete: existing only, never new**
The board-formed texture is the texture of the existing building's specific
era and construction process. Applying it to new construction would produce
a color and texture mismatch that reads as failed replication.
Smooth concrete for new work. The decision is not to hide from the contrast —
it is to make the contrast deliberate.
Reference: New concrete behavior (T1 materials science), precedent (T2)
Confidence: CONFIRMED

## Performance Decisions

**D09 — South-facing glazing with 1.9m horizontal brise-soleil**
Calculated from solar angle at this latitude. The depth (1.9m) is determined
by the requirement to shade summer sun fully while admitting winter sun.
The projection depth is structurally significant — it must be cantilevered
from the column line, which affects the structural specification.
Reference: Solar angle calculation for latitude (T1), climate data (T1)
Confidence: CONFIRMED — calculation verified by structural engineer

**D10 — Existing glazing: secondary interior glazing, not replacement**
Replacing the existing single-glazed aluminum frames would disturb the
expressed frame — a governing rule violation. Interior secondary glazing
achieves the target U-value improvement from 1.8 to 1.0 W/m²K without
touching the existing expressed elements.
Reference: Existing envelope condition (T1), governing rule (T1 derived)
Confidence: CONFIRMED

**D11 — Recording booth: structurally isolated (floating floor, isolated ceiling)**
Acoustic isolation to NR25 requires structural decoupling from the slab.
Standard acoustic practice, confirmed by acoustic consultant.
Reference: Site acoustic measurement (T1), acoustic engineer's specification (T1)
Confidence: CONFIRMED

## The "NEVER" List (Written into Schematic Design Package)

1. Never replicate board-formed concrete texture on new construction
2. Never allow extension to exceed existing parapet height
3. Never obscure an expressed structural element of the existing building
4. Never compete with the existing primary entrance
5. Never hide the extension structural columns behind cladding
6. Never apply decoration to new concrete elements
7. Never specify new concrete expecting it to match existing — the color
   difference is a feature, not a failure
