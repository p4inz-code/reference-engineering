# Brand Identity — Outcome & Decisions

---

## Mark Decisions

**D01 — Mark form: single enclosed form, not monogram**
Rule: quiet = single form, generous negative space. Monogram (HS) was
considered and rejected — two-letter monograms read as corporate.
Form chosen: abstract signal/wave form suggesting transmission and distance.
Reference: Mark complexity analysis across 12 indie studio marks (T2)
Confidence: SUPPORTED

**D02 — Mark weight: medium stroke, not thin, not bold**
Thin marks read as ethereal (wrong register). Bold marks read as assertive
(wrong register). Medium stroke at correct optical size reads as present
without loudness.
Reference: Type and mark weight analysis (T2)
Confidence: SUPPORTED

**D03 — Mark at 32×32: remains legible as a recognizable form**
Tested at 32×32 before refinement. Form simplification passes readability.
Reference: Primary platform specification (T1)
Confidence: CONFIRMED — production-tested

## Color System Decisions

**D04 — Background: #1C2127 (dark blue-gray)**
Not black (#000000). Not neutral dark gray (#1E1E1E). Slight blue shift.
Luminance: approximately 8%. Reads as dark without being stark.
Reference: A24 film and ambient album art color analysis (T2/T3)
Confidence: SUPPORTED

**D05 — Primary mark/type: #E8EBE8 (off-white, neutral)**
Not white. Not warm cream. Near-neutral with extremely slight cool cast.
Contrast against #1C2127: approximately 10.5:1 (passes WCAG AAA).
Note: intentionally below theoretical maximum contrast for the "not stark" rule.
Reference: Extracted color rule — off-white on dark gray, not white on black (T2)
Confidence: SUPPORTED

**D06 — Accent: #4A7A7F (muted teal) — optional use only**
Never dominant. Used only for interactive states or rare emphasis.
Saturation: 22%. Very muted. Not "teal" in the way most people visualize
teal — closer to a desaturated sea color.
Reference: Ambient music album art, indie game emotional color mapping (T2/T3)
Confidence: PROVISIONAL — accent color use requires client sign-off

**D07 — Light background version: #1C2127 mark on #F2F2F0 background**
Off-white background (not white) maintains the "not stark" rule even inverted.
Reference: Derived rule — avoid pure contrast pairs (T2 extracted rule)
Confidence: SUPPORTED

## Typography Decisions

**D08 — Wordmark typeface: humanist sans, regular weight**
Selected: Inter Regular (free, excellent rendering across all digital platforms)
Considered and rejected: Helvetica (too geometric, too corporate),
Garamond (too literary/historical, different register), DM Mono (too technical)
Inter Regular occupies the "considered, workmanlike, unshowy" position the
rules specified.
Reference: Type analysis across 8 atmospheric game studios (T2)
Confidence: SUPPORTED

**D09 — Tracking: +60 units (slight expansion)**
Wider than default. Creates the "considered, not rushed" quality.
Not so wide as to read as retro or decorative.
Reference: Tracking analysis across category (T2), confirmed by visual test
Confidence: SUPPORTED — validated against reference examples

**D10 — Case: mixed case ("Hollow Signal" not "HOLLOW SIGNAL")**
All-caps rejected: reads as assertive. All-lowercase considered (more indie)
but rejected: too casual for a studio trying to signal seriousness.
Mixed case: appropriate weight.
Reference: Case analysis across category (T2)
Confidence: SUPPORTED

## Brand Guide Decisions

**D11 — What the brand NEVER does (written into brand guide)**
1. White on black — no pure contrast pairings
2. Bold weight in any application
3. All-caps wordmark
4. Saturated accent colors (no full-saturation colors in any application)
5. More than one accent color
6. Mark used at sizes below 32×32 without testing
7. Mark cropped or combined with other graphic elements
Reference: Derived from register mapping (T2), competitor misread analysis (T2)
Confidence: CONFIRMED — all rules have reference support
