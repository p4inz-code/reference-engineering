## Layer 1 — Function & Context Reference

### Primary Display Context: itch.io (dark background)
*Answers: "Where will this brand be seen first?"*
itch.io default: dark gray background (#1E1E1E approximately).
White or light marks read well. Dark marks disappear.
Primary brand must read on dark backgrounds.
Light-background version: secondary, required for Steam.
Hierarchy tier: **Primary** — direct platform documentation

### Audience Reference: Indie Game Community Brand Touchstones
*Answers: "What brands does the target audience already respond to?"*

Research: indie game community on itch.io and Twitter/X identifies these
studio brands as respected/admired in the atmospheric exploration genre:
- **Annapurna Interactive** — publisher, not dev, but widely cited as
  tone reference. Warm off-white + muted terracotta. Sans-serif, wide-tracked.
  Reads as: considered, independent, film-adjacent.
- **Fellow Traveller** — publisher for narrative games. Dark palette.
  Upper/lowercase mix. Reads as: literary, thoughtful.
- **Amanita Design** — Czech studio, Machinarium/Samorost. Organic,
  illustration-forward. Different execution but same emotional register.
- **Corollary Arts** — small studio, strong brand. Dark forest greens,
  monoweight sans. Reads as: quiet confidence, not striving.

What these brands share: restraint. None of them are loud. None are
bright. None use display typefaces with personality — they use workmanlike
type and let color and space do the emotional work.
Hierarchy tier: **Primary** — direct category research

## Layer 4 — Governing Rules Reference (Primary Focus)

### Register Mapping: Melancholy vs Adjacent Misreads
*Answers: "What makes this brand misread as horror, generic minimalism, or corporate?"*

This is the most important reference work in this project. The brief says
"melancholic" but melancholy shares visual territory with several registers
that would be wrong.

| Register | Distinguishing Parameters | Risk for This Project |
|---|---|---|
| **Melancholy (target)** | Muted, cool-leaning, low contrast, weighted type | Correct |
| **Horror** | High contrast, sharp geometry, aggressive tracking, red accent | Wrong if: high contrast, red, aggressive mark |
| **Generic minimalism** | Pure white/black, no temperature, Swiss grid | Wrong if: too neutral, no emotional temperature |
| **Corporate** | Geometric sans, high saturation accent, clean proportions | Wrong if: too polished, too confident |
| **Ethereal** | Very light palette, thin marks, extensive white space | Wrong if: too airy — lacks weight and melancholy implies weight |

**The line between melancholy and horror:** contrast. Horror uses high
contrast (black backgrounds, white or red type, shock values). Melancholy
uses low contrast — muted, not stark. Dark backgrounds for this brand
should be dark gray, not black. Light elements should be off-white, not white.

**The line between melancholy and generic minimalism:** temperature.
Generic minimalism is thermally neutral. Melancholy has a temperature —
cool to slightly warm, desaturated, but not neutral. The difference between
#888888 (neutral) and #7A8A8E (cool blue-gray) is the difference between
generic and intentional.

Hierarchy tier: **Secondary** — adjacent register analysis

### Type Reference: Atmospheric Indie Game Studios
*Answers: "What type characteristics define this register?"*

Analysis across 8 indie game studios in the atmospheric exploration genre:

| Parameter | Common finding | Outliers |
|---|---|---|
| Family | Humanist sans or transitional serif | 2/8 used geometric sans |
| Weight | Regular to medium — never bold, never thin | — |
| Tracking | Slightly wide (50–100 units) | — |
| Case | Mixed case or all-lowercase — never all-caps | 1/8 used caps |
| Optical size | Text weight (not display) | — |

**Extracted type rules:**
1. Humanist sans or transitional serif — not geometric, not grotesque
2. Regular weight — never bold (bold reads as confident/loud), never thin (thin reads as ethereal)
3. Slightly wide tracking (50–100 units) — creates considered, not rushed quality
4. Mixed case preferred over all-caps (all-caps reads as assertive)
5. Optical text weight — this brand does not shout

Hierarchy tier: **Secondary** — adjacent genre analysis with translation

### Color Reference: "Atmospheric" Parameters
*Answers: "What color properties define atmospheric?"*

**From film: A24 atmospheric films (Hereditary excepted — that's horror)**
Midsommar, Moonlight, The Witch (pre-horror):
- Desaturated but not neutral — always slightly cool or slightly warm
- Value range: dark backgrounds in the 15–25% luminance range (not black)
- Accents: none or extremely muted
Pattern: the emotional weight comes from value and temperature, not from saturation.

**From music: ambient/post-rock album art (Explosions in the Sky, Stars of the Lid)**
- Heavily desaturated photography or illustration
- High use of deep blue-gray and muted teal
- White or very light type
Pattern: blue-adjacent grays are the dominant tool in this aesthetic register.

**From indie game: Journey, Abzû, Flower (for reference — different studio)**
- Color is used for emotional phase (warm = safety, cool = unknown)
- Saturation increases at emotional peaks, decreases at quiet/melancholic moments
Translation: our brand is in the "quiet/melancholic" phase — low saturation, cool temperature.

**Extracted color rules:**
1. Background: dark gray, not black. Target: #1A1E22 to #252B30 range
2. Primary mark/type: off-white, not white. Target: #E8EAE8 to #F0F0EC range
3. Temperature: cool. All neutrals have a slight blue-green shift
4. Saturation: very low. No pure colors. Everything is muted
5. Accent: one, optional, muted. If used: muted teal or desaturated amber only
6. Contrast ratio: moderate, not high. Avoid stark black/white pairings

Hierarchy tier: **Secondary/Tertiary** — cross-domain extraction

### Mark Complexity Reference: "Quiet" Visual Weight
*Answers: "What mark characteristics define quiet?"*

Research across 12 indie game studio marks:
- Marks with more than 3 visual elements read as active/busy
- Marks with geometric precision read as technical/corporate
- Marks with organic variation read as handcrafted/small-studio
- The most "quiet" marks are single forms with generous negative space

Pattern: quiet = simple mark, generous negative space, no visual tension.
Active = multiple elements, tight spacing, competing visual forces.

Applied rule: Hollow Signal mark should be a single form (not a monogram,
not a multi-element composition). Generous negative space inside the mark
and around it.

Hierarchy tier: **Secondary** — category analysis

## Layer 5 — Contextual Conditions Reference

### Primary Context: Dark Background Digital
itch.io, Discord, game loading screens. Dark background assumed.
Brand must perform at:
- 512×512 (Steam capsule, itch.io icon)
- 200×200 (Discord server icon, small Steam logo)
- 32×32 (browser favicon)
- 1200×630 (social card / Steam header crop)

At 32×32: wordmark is completely illegible. Mark must carry brand solo.
Mark must be designed for legibility at 32×32 before any other consideration.
Hierarchy tier: **Primary** — direct platform specification

### Secondary Context: Light Background (Steam)
Steam occasionally displays brands on light backgrounds in search results.
Brand must not break at light background — inverted version required.
Not the primary design direction.
Hierarchy tier: **Primary** — platform documentation

## Gap Audit

### Resolved
All critical gaps resolved through reference work.
"Melancholy" is now defined as: low contrast, cool temperature, off-white
on dark gray, humanist type, regular weight, muted. This is evaluatable.

### Remaining
**GAP 01: Client confirmation of competitive positioning**
The analysis assumes Hollow Signal wants to occupy the "considered/literary"
position alongside Corollary Arts and Fellow Traveller. If they want to
be closer to Amanita Design's more illustrative approach, the mark
complexity rules change significantly. Client must confirm before mark development.
