# Example: Independent Studio Brand Identity

**Discipline:** Brand Design
**Project type:** Brand identity system for a small independent game studio
**Project prompt:** Design a brand identity for a two-person indie game studio
  called "Hollow Signal." They make atmospheric exploration games — slow,
  quiet, melancholic. No combat. Think walking simulators with strong
  environmental storytelling. Audience: itch.io and Steam indie game community.
  Budget: minimal. Deliverables: logo, wordmark, color system, one-page
  brand guide.

**Framework focus:** Layers 1, 4, and 5 dominate. Brand identity reference
work is almost entirely about extracting written rules (Layer 4) from
competitor and adjacent-field reference. This example demonstrates how
Reference Engineering prevents the most common brand design failure:
visual mimicry without rule extraction.

**Key skill demonstrated:** Translating a subjective brief ("atmospheric,
melancholic") into specific, measurable visual parameters that a designer
can execute consistently — and that a client can evaluate against something
other than feeling.
