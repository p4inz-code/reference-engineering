# Brand Identity — Problem & Brief

**Project:** Hollow Signal — Indie Game Studio Brand Identity
**Stage:** Pre-production / concept stage

---

## The Problem Without Reference Engineering

Brand identity projects routinely fail at the reference stage in one of two ways:

**Failure Mode A — Visual Mimicry:** The designer finds studios with aesthetics
they like, copies the surface (dark palette, minimal type, geometric logo),
and delivers work that looks "in the genre" but has no specific relationship
to the client. The client cannot evaluate it except by feeling. Revisions
are endless because there is no standard to evaluate against.

**Failure Mode B — Undirected Mood Board:** The designer collects 80 images
that "feel right" and makes decisions from that ambient sense of correctness.
The work produced has internal consistency but no documented rationale.
When the client asks "why this color?" the answer is "it felt right for the
mood you described." This is not a reference-backed decision.

Reference Engineering for brand identity replaces both failure modes with
a written, extractable rule set derived from specific reference.

## Production Questions This Brief Must Answer

### Layer 1 — Function & Context

- [ ] Where will this brand be seen? (itch.io store page, Steam page, Twitter/X, GitHub, game loading screen — rank by priority)
- [ ] Who is the primary audience and what brands do they already respond to? (indie game community — what studios do they cite as reference points?)
- [ ] What is the brand's competitive positioning? (what makes Hollow Signal different from other atmospheric game studios?)
- [ ] What does "atmospheric, melancholic, quiet" mean in the specific context of indie game brand design — not in the abstract?
- [ ] What does the brand need to communicate in its smallest form? (16×16px favicon is the hardest constraint)

### Layer 2 — Scale & Proportion

- [ ] What are the primary lockup sizes and aspect ratios needed? (horizontal lockup for Steam header, square for avatar/icon, standalone mark for favicon)
- [ ] What is the minimum legible size for the wordmark at primary display contexts?

### Layer 3 — Production Stage (Concept)

*At concept stage: need reference for visual direction, not finished execution.*
- [ ] What existing brands in the indie game space occupy the "atmospheric/melancholic" position?
- [ ] What adjacent non-game brands occupy a similar emotional register? (film, music, literature)
- [ ] What does the wrong version of this aesthetic look like? (what would make this brand misread as horror, or as generic minimalism, or as corporate?)

### Layer 4 — Governing Rules

- [ ] What specific visual parameters define "melancholic" vs "depressing" vs "horror" vs "ethereal"?
- [ ] What type characteristics belong in this register? (serif vs sans, weight, tracking, cases)
- [ ] What color properties define "atmospheric"? (saturation range, value range, temperature)
- [ ] What mark characteristics define "quiet"? (complexity, weight, positive/negative space ratio)
- [ ] What does this brand NEVER look like? (the most useful constraint)

### Layer 5 — Contextual Conditions

- [ ] What display contexts does this brand live in? (primarily dark-background digital contexts — itch.io dark mode, game loading screens, Discord)
- [ ] Does the brand need to work on light backgrounds? (minimal — but Steam sometimes forces light mode)
- [ ] What color rendering should the brand be designed for? (sRGB, digital-first — no print primary)

## Reference Tier Plan

| Question category | Expected tier | Source plan |
|---|---|---|
| Indie game studio brands | Primary | Direct research: itch.io, Steam, studio websites |
| "Atmospheric" visual parameters | Secondary | Adjacent fields: film, music, literary publishing |
| Color psychology for melancholy | Tertiary | Color theory, visual perception research |
| Type characteristics for the register | Secondary | Type foundry editorial context, adjacent brands |

## Gap Risk Assessment

| Gap | Risk if unresolved | Priority |
|---|---|---|
| "Melancholic" parameters not defined | HIGH — all visual decisions contested without this | CRITICAL |
| Wrong register risk not mapped | HIGH — could deliver horror brand instead of melancholy brand | CRITICAL |
| Smallest form constraints not confirmed | MEDIUM — may not work at favicon/avatar size | HIGH |
