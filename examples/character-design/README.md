# Example: Character Design — All Seven Pyramid Layers

**Discipline:** Character Art / 3D Character Design
**Project type:** Original character for a stylized action RPG
**Project prompt:** Design and model a playable character for a stylized
  action RPG. The character is a 30s-era archaeologist-adventurer — part
  Indiana Jones archetype, part pulp novel cover. Stylized realism: slightly
  exaggerated proportions, strong silhouette, readable at third-person camera
  distance. Target: UE5, third-person, hero asset quality.

**Framework focus:** This is the most complete example in the library —
all seven Pyramid layers are demonstrated explicitly. It also demonstrates
the Brief Lifecycle across two versions: v1 (pre-production) and v2
(post-blockout), showing what production reveals that pre-production misses.

**Key skills demonstrated:**
- Full seven-layer coverage
- Brief versioning in practice (v1 → v2)
- Reference Hierarchy across all three tiers in a single project
- "What this design NEVER does" as a primary design constraint
